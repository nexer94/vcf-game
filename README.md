# VCF Game

Webová 2,5D hra / simulátor, který věrně modeluje **VMware Cloud Foundation 9.x** podle oficiální
dokumentace Broadcom (aktuálně VCF 9.1.1).

- Pravidla pro Claude (orchestrátor): [`CLAUDE.md`](CLAUDE.md)
- Subagenti: [`.claude/agents/`](.claude/agents/)
- Znalostní báze (zdroj pravdy): [`docs/spec/`](docs/spec/)
- Grafický design: [`docs/design/GRAPHICS.md`](docs/design/GRAPHICS.md)
- Stav projektu: [`docs/PROGRESS.md`](docs/PROGRESS.md)

## Jak pracovat
Otevři repozitář v GitHub Codespaces, spusť Claude Code a napiš třeba:
> Začni session podle CLAUDE.md a pokračuj dalším krokem z PROGRESS.md.

Simulace je vzdělávací model, ne oficiální produkt Broadcomu.
